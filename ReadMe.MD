This is a calculator app. The idea for this project came to me when I was looking through old files and saw a basic python calculator I'd made. I decided to improve the calculator. Currently, the calculator can perform:
- Linear equations
- Simultaneous Linear Equations (wip)
- Quadratic Equations (future)
- Trigonometry(future)
- Calculus(future)
- Statistics(future)
- Unit Conversions(future)

I currently don't know what else to add, so leave your suggestions either on the repo as issues or on Hack Club as a comment.
