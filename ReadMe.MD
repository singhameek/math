This is a calculator app. The idea for this project came to me when I was looking through old files and saw a basic python calculator I'd made. At the time, I'd just been experimenting with Streamlit, but now, after 3 websites built with it, I thought "why not?" and decided to improve the calculator and turn it into a site. Currently, the calculator can perform:
- Linear equations
- Simultaneous Linear Equations
- Quadratic Equations
- Trigonometry
- Calculus
- Statistics
- Unit Conversions

I currently don't know what else to add, so leave your suggestions either on the repo as issues or on Hack Club as a comment.
